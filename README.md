# ShadowGuard-FIM

## 🚀 Key Capabilities

- Real-time file integrity monitoring (FIM)
- Detection of credential access attempts (MITRE T1003)
- Permission tampering detection (MITRE T1222)
- Behavior-based alert scoring
- Source attribution (local vs remote)
